## 审查重点

1. **架构对齐**:代码是否忠实实现设计(不偏离、不过度)
2. **工程完备**:测试覆盖、日志、监控、回滚
3. **代码规范**:命名、注释、风格一致性
4. **可维护性**:耦合度、复用性、可读性
