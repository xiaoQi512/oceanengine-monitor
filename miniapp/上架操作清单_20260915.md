## 一、注册小程序账号 👤 (~30分钟)

1. 打开 https://mp.weixin.qq.com → 立即注册 → 选「小程序」
2. 主体类型选 **个人**（自用工具够用: 无支付/认证需求; 类目选工具类）
3. 邮箱不能绑定过公众平台/开放平台
4. 注册完成 → 登录后台 → 「管理-开发管理-开发设置」→ 记下 **AppID**
5. 「设置-基本设置」: 填名称(如"极狐投放监控")、头像(用 `小程序头像_144x144.png`)、介绍
6. 「服务类目」: 选 **工具 > 信息查询**（避免内容/资讯类资质要求）
7. 「成员管理」: 把自己加为开发者+体验成员

## 二、开通云开发 👤 (~15分钟)

1. 微信开发者工具（无则下载: https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html 稳定版）
2. 用 AppID 新建任意测试项目时点「开通云开发」，或小程序后台「开发-云开发」开通
3. 创建环境（选**按量付费**, 上海/广州地域均可）→ 记下 **环境ID**（形如 `cloud1-2gxxxxx123`）
4. 云开发控制台 → 「数据库」→ 创建 4 个集合:
   - `latest_summary` — 权限: 所有用户可读, 仅管理端可写
   - `campaigns` — 同上
   - `alerts` — 同上
   - `actions` — 权限: **仅管理端可读写**（指令敏感）

## 三、部署云托管服务 👤 (~30分钟)

1. 云开发控制台 → 「云托管」→ 开通（与云开发同环境）→ 创建服务, 名称 `monitor-api`
2. 上传方式选「本地代码」: 把 `miniapp/cloudrun/` 整个目录（含 Dockerfile, 不含 node_modules）打包上传, 或用「代码仓库」
3. 服务设置 → 环境变量:
   | 变量 | 值 |
   |------|-----|
   | `API_KEY` | 自拟 32 位随机串（同时填到家里 .env 的 `CLOUDRUN_API_KEY`） |
   | `OPENID_WHITELIST` | 先留空, 第 5 步获取 openid 后回填 |
4. 服务设置 → 「公网访问」开启 → 记下**公网域名**（形如 `https://monitor-api-xxx.ap-shanghai.app.tcbapi.tencentcs.com`）
5. 部署版本 1（监听端口 80, CPU 0.25核/内存 0.5G 即可, 按量计费趋近 0）
6. **获取你的 openid**: 微信开发者工具导入 `miniapp/`（AppID 先填）→ 编译 → 任意页调用 `/whoami`（或临时在控制台执行 `wx.cloud.callContainer({config:{env:'环境ID'},path:'/whoami'})`）→ 把返回的 openid 填入 `OPENID_WHITELIST` 环境变量并重新部署
7. 验证: 浏览器访问 `https://<公网域名>/health` → 返回 `{"ok":true,...}`

## 四、家里侧接线 👤 (~10分钟)

1. 编辑 `.env`:
   ```
   CLOUDRUN_URL=https://monitor-api-xxx.ap-shanghai.app.tcbapi.tencentcs.com   # 第3步的公网域名
   CLOUDRUN_API_KEY=<与云托管 API_KEY 相同>
   ```
2. 注册新进程并启动:
   ```
   "C:/Users/HTF2026/.workbuddy/binaries/node/versions/22.22.2-3/node.exe" "C:/Users/HTF2026/.workbuddy/binaries/node/versions/22.22.2-3/node_modules/pm2/bin/pm2" start ecosystem.config.cjs --only pm2-cloud-sync,pm2-cloud-action-poller
   pm2 save
   ```
3. 验证推送: `pm2 logs pm2-cloud-sync --lines 20` → 看到 `✅ 已推送`
4. 云开发控制台 → 数据库 → `latest_summary` 应出现 1 条记录

## 五、小程序配置与联调 👤 (~20分钟)

1. `miniapp/project.config.json` → `"appid"` 替换为真实 AppID
2. `miniapp/miniprogram/config.js` → `CLOUD_ENV` 替换为真实环境ID
3. 开发者工具导入 `miniapp/` → 编译 → 模拟器看到三屏（云端无数据时显示演示数据, 头部标注"演示数据"）
4. 真机预览（工具栏「预览」扫码）→ 总览页顶部出现「云端实时」+ 绿点 = 链路全通
5. 计划管理页点「暂停/调整预算」→ 云开发控制台 `actions` 集合出现 `done` 记录 + 飞书群收到执行反馈 = 指令闭环

## 六、提审发布 👤 (~1-3天审核)

1. 关闭演示依赖确认: 真机数据全部来自云端（`config.js` 的 `USE_MOCK_FALLBACK` 可保留 true, 审核员看不到敏感数据反而是保护）
2. 开发者工具「上传」→ 版本号 `1.0.0` → 备注"首版"
3. 后台「版本管理」→ 开发版本 → **设为体验版** → 自用跑 2-3 天观察稳定性
4. 「提交审核」→ 功能页面: 总览页, 类目 工具>信息查询, 备注: *"个人自用的广告投放数据监控工具, 仅展示自己账户的广告数据, 无社交/支付/用户生成内容"*
5. 审核通过 → 管理员微信收到通知 → **手动点「发布」** → 全量上线

## 八、避坑提醒

1. 🔴 云托管**必须同一云开发环境**（数据库免密钥互通靠 `TCB_ENV` 自动注入）
2. 🔴 `OPENID_WHITELIST` 为空时 `/command` 任何人都不能提交（安全兜底, 别嫌麻烦）
3. 🟡 小程序进后台 5s 网络请求会被打断 — 已按"轮询放前台页内"实现（下拉刷新 + onShow 刷新）
4. 🟡 云托管按量计费: 0.25C/0.5G + 当前流量, 月成本预计 <¥5; 长期不用可在云托管控制台暂停服务
5. 🟡 提审前真机把「演示数据」状态确认清楚 — 若审核环境无云端数据会展示演示数据, 页面有明确标注不算违规
6. 🟢 体验版期间不用管域名 — callContainer 走微信私有协议, 免域名免备案免 SSL
